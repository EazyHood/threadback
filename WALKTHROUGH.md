# Try a return, not just a task list

Open [Threadback](https://eazyhood.github.io/threadback/). No account is needed. Use fictional notes in the public demo.

1. Choose **Try the study example**. The banner identifies the two cards as synthetic. The first card puts the next calculation beside its exact question and the decision behind it.
2. Open **Open the synthetic practice sheet**. Question 3b is part of the working demo. Return to Threadback and choose **Resume this step**. The card becomes active; it is not finished.
3. Choose **Leave my next return card**. Change the next action to a sentence you can act on later, then keep the card. Expand **Previous return cards · latest 5** to compare the previous context. Only the five most recent previous cards are retained.
4. Select **Group report · methods section**. The missing dataset stays visible with an alternative written in the example. Choose **Review this blocked plan** to revise the context. Keeping the blocker keeps the card blocked. Finish and reopen only if you want to test those separate states.
5. Optionally enable **Browser saving**, confirm the saved state, then reload. The cards return in this browser. A separate browser profile or device will not have them.
6. Edit a card and choose **Keep draft & close**. Export a backup, then import the downloaded JSON using **Import backup**. Review the replacement confirmation: the backup includes the unfinished draft as well as the cards.

To try your own blank card, use **Leave a return card**. Only a title and a next action are required. References, the exact place, a previous decision and a blocker are optional context.

The purpose is to preserve what you wrote, not to invent the next step or decide whether your work is complete. Browser-local saving can be lost; JSON export is a manual backup. [Validation](VALIDATION.md) records the checks and their limits, and [credits](CREDITS.md) disclose AI assistance and prior conceptual work.
