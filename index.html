    A new Taskforge prototype made with substantial OpenAI Codex assistance. The earlier Benchkeep project also explored pause and return; this academic workflow and code are new. No student study, time saved or learning outcome is claimed. There is no account, AI service, analytics or note-submission service. The host receives ordinary page requests.
